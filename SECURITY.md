# Security policy

Please report security-sensitive issues privately through GitHub's private vulnerability reporting feature if it is enabled for this repository. Do not put RetroAchievements passwords, tokens, private configuration files, ROMs, or unsanitized logs in a public issue.

The plugin stores its RetroAchievements token in plain text in `1964-ra.ini` beside `1964.exe`. Anyone who obtains that token may be able to access the associated account. Delete or replace the token immediately if it is exposed.

Only the latest release is supported. This experimental project does not claim to provide a hardened security boundary.
