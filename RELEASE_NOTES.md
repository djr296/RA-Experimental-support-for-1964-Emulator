# 1964GEPD RA Proxy v0.1.0 — experimental Casual-mode beta

This is an unofficial test release that adds RetroAchievements to GoldenEye 007 and Perfect Dark when using the 1964 GEPD Edition and its existing Mouse Injector.

## Before installing

- Casual achievements only; Hardcore is forcibly disabled.
- This client is experimental and is not listed as an approved RetroAchievements emulator.
- Download 1964 GEPD separately from its official upstream release page.
- You must supply your own legally obtained ROM. No ROMs or game assets are included or linked here.
- Back up your emulator folder first.

See `README.md` for installation, removal, privacy, limitations, and source-build instructions.
