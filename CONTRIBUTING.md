# Contributing

Bug reports and source contributions are welcome, especially reproducible fixes for GoldenEye 007 or Perfect Dark that preserve the performance and compatibility of the 1964 GEPD Edition.

By submitting a contribution, you agree that it may be distributed under GPL-2.0-or-later.

Do not submit ROMs, game code or assets, copyrighted artwork, account credentials, achievement tokens, or files copied from incompatible sources. Keep Hardcore disabled unless RetroAchievements has reviewed and approved a complete compliant integration.

Before submitting a pull request:

1. Build the 32-bit DLL successfully.
2. Confirm all 15 plugin exports still load.
3. Test GoldenEye 007 and Perfect Dark in Casual mode.
4. Confirm fullscreen, mouse input, sound, and normal frame rate still work.
5. Describe the tests in the pull request without sharing ROM files or hashes that are not already public on RetroAchievements.
